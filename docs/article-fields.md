# 封面与自定义参数

在文章、草稿或页面编辑器右侧点击 **封面与自定义参数**。手机端入口位于正文下方的文章信息区域。

## 设置封面

1. 选择或输入主题使用的字段名，默认 `cover`，也可填写 `top_img`、`banner`、`thumbnail` 等。
2. 填写图片地址，或使用“上传封面”“从图片库选择”。支持 PNG、JPEG、GIF 和 WebP；云端上传最大 3 MB，本机 / 桌面版最大 8 MB。
3. 点击“预览图片”检查。后台只预览可访问的 HTTPS 图片和自身图片库；文章资源目录等相对路径仍可保存，最终显示需在博客中确认。
4. 点击“应用到文章”，再点击编辑器的“保存”。

“清除字段”会在应用时移除当前封面字段，不删除图片文件。切换封面字段会切换正在编辑的参数，不会自动删除其他封面字段。图片上传会立即保存到博客图片库，云端同时产生仓库提交；关闭参数窗口不会撤销已上传的图片。

## 编辑自定义参数

展开“自定义参数”查看文章已有字段，或者输入名称添加新字段：

| 类型 | 示例 |
| --- | --- |
| 文本 | `description`：文章摘要；文本 `false` 会保持为字符串 |
| 布尔值 | `comments: false`、`featured: true` |
| 数字 | `sticky: 3`，仅适用于支持该字段的主题 |
| YAML | 数组、嵌套对象或 `null`，例如 `{ enable: true, levels: [2, 3] }` |

字段名称支持以英文字母或下划线开头，后续可包含字母、数字、下划线、连字符和点，最多 64 字符。标题、日期、标签和分类使用原有基础信息表单编辑。带锚点、引用或自定义标签的字段会显示为只读，可继续在正文编辑器中直接修改 YAML。

修改只应用于选中的字段，正文、其他字段和未修改字段的注释保持原样。应用后可以在 Markdown 文首检查结果；未保存前不会写入文章文件或远端仓库。原有的冲突检测和本机未保存草稿备份继续生效。

## Morii 主题示例

Morii 使用 `cover` 作为文章卡片封面，顶部大图优先使用 `top_img`，未设置时使用 `cover`。以下组合保留卡片图片并关闭顶部大图：

```yaml
cover: /images/hexostudio/example.jpg
top_img: false
description: 记录生活中的灵感。
featured: true
comments: false
```

这些参数由主题解释；添加一个字段不会让不支持它的主题自动增加对应功能。全站主题设置仍在“站点配置”中编辑。
