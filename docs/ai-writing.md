# AI 辅助写作

网页、本机与桌面版共用 AI 写作功能。需要自行准备支持 **OpenAI Chat Completions** 协议的服务与 API Key，费用由该服务商收取。

## 配置服务

登录管理员后，打开侧栏的 **AI 设置**，填写：

| 字段 | 填写方式 |
| --- | --- |
| 服务地址 | API 基础地址，例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com`，不是服务商网站或聊天页面 |
| 模型名称 | 服务商提供、且你的 Key 有权使用的模型 ID |
| API Key | 服务商创建的 API 密钥 |

保存后即可使用。保存仅校验配置格式，**不会发起收费的生成请求或验证余额**。已保存的密钥不会回显；留空可保留，更换服务地址时必须重新输入密钥。点击“移除配置”会关闭 AI 写作并删除该配置，不影响文章。

## 开始写作

- **新文章 / 大纲**：在概览或文章管理点击“AI 写作”，填写标题、写作要求和输出语言。生成后可直接修改 Markdown，点击“保存为草稿并编辑”继续写作。
- **插入内容**：在编辑器中放置光标，点击工具栏“AI 写作”，选择生成文章或大纲。确认后插入光标处，再手动保存。
- **润色选区**：先选中正文，再点击“AI 写作”。检查“将发送的选中文字”，生成后点击“替换选中文字”。不会替换文首 YAML 配置；如果编辑器内容发生变化，插入会被阻止以避免覆盖。

生成结果不会自动发布。云端点击保存草稿会向博客仓库的 `source/_drafts` 写入一次提交；本机 / 桌面版写入对应本地目录。

## 数据与密钥

只在点击“生成内容”时发送文章标题、写作要求，以及润色模式下主动选中的文字。不会自动上传整篇文章或博客仓库。生成前会显示目标服务域名；请核对事实与引用，并遵守所选服务的数据使用政策。

请求由服务端发出，API Key 不会回传到浏览器。本机 / 桌面版将其保存在当前设置文件（POSIX 权限 `0600`）；云端随应用状态加密存入数据库，依赖部署时配置的 `HEXOSTUDIO_SECRET`。请妥善管理设置文件、数据库备份和部署密钥。

## 兼容性与限制

- 请求使用 `POST {服务地址}/chat/completions`、Bearer 认证和非流式文本响应。不支持仅提供 Responses API 的服务或要求额外认证头的端点。
- 服务地址必须是公网 HTTPS；不支持 localhost、内网 IP 或 HTTP。每次请求检查 DNS 并固定连接地址，不跟随重定向。
- 单次请求超时约 45 秒；每个 HexoStudio 实例 / 云端应用每 10 分钟最多 10 次、同时最多 1 次生成。失败请求也计入限额。
- 写作要求最多 6000 字符，润色选区最多 16000 字符；输出预算为 4096 tokens，是否包含推理 token 取决于模型。达到上限时页面会提示内容可能未完成。
- 使用官方 OpenAI 地址时发送 `max_completion_tokens`，其他兼容服务发送 `max_tokens`。具体模型仍需支持上述参数与 system / user 消息。
- 云平台自身的函数时限也可能中断请求；部署时应为生成请求预留足够时间。请求不会自动重试，避免重复计费；上游已受理的失败请求仍可能产生费用。

遇到拒绝访问，检查 Key、模型权限和余额；遇到地址或模型错误，检查基础地址及 Chat Completions 支持情况。没有返回正文时可尝试非推理模型或缩短任务。

协议参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat)、[DeepSeek Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion/)。
