# 图表与数学公式预览

文章、草稿和独立页面的「实时预览」支持 Mermaid 与 KaTeX。保存时保留 Markdown 源文，不改写为 HTML。博客发布后的渲染由 Hexo 渲染器与主题配置决定，后台预览不会自动安装或修改主题插件。

## Mermaid

使用标记为 `mermaid` 的代码块：

````markdown
```mermaid
flowchart LR
  A[编写文章] --> B[实时预览]
  B --> C[确认并发布]
```
````

图表随深浅色切换，支持展开查看源码。语法错误会显示提示，并保留源码及文章其他预览内容。每次预览最多渲染 6 张图，单图最多 12,000 字符、200 条边；超出时显示源码。

图表在不具备后台同源权限的沙箱中渲染，使用 strict 安全模式，不启用图表中的点击回调和外部资源。脚本随应用分发，不依赖 CDN。

## 数学公式

行内公式使用单美元符号：

```markdown
能量公式为 $E=mc^2$。
```

独立公式使用双美元符号：

```markdown
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

支持 KaTeX 的常用 LaTeX 数学语法。代码块和行内代码中的公式保持原样；普通价格与转义美元符号不会自动转换。无效公式显示红色源码，其他预览继续渲染。不启用公式中的外部链接、图片与 HTML 扩展。单式最多 10,000 字符，每次预览最多排版 200 个公式。

## 更新离线资源

维护者升级 Mermaid 或 KaTeX 后，运行 `npm run preview:assets`，提交 `public/vendor/` 与 `public/preview-assets.json`。这一步仅复制 npm 包提供的浏览器资源及许可证；生产安装无需 Mermaid 开发依赖，也不需要联网获取字体。
